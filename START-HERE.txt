Bulk Publisher Studio

1. Install Node.js 24 or later (22.18+ also accepted).
2. Extract the entire ZIP into a NEW empty folder. Double-click START-WINDOWS.cmd.
   Or open CMD in that folder, beside package.json AND package-lock.json.
   Older ZIPs put the app in a nested bulkpublisher folder: cd bulkpublisher
3. Run:

   npm ci
   npm run setup:local
   npm start

4. Open http://127.0.0.1:8787
5. Sign in: admin / admin

Change ADMIN_PASSWORD in the private .dev.vars file before sharing access.
