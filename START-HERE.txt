Bulk Publisher Studio

1. Install Node.js 24 or later (22.18+ also accepted).
2. Open a terminal in this folder, beside package.json.
3. Run:

   npm ci
   npm run setup:local
   npm start

4. Open http://127.0.0.1:8787
5. Sign in: admin / admin

Change ADMIN_PASSWORD in the private .dev.vars file before sharing access.
